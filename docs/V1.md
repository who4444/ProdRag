# ProdRag v1 — R&D Demo System (idea → research → code)

**Status:** shipped v1 (2026-09-01) — 137 tests, `idea → research → code` end-to-end, sandbox-verified `demo.py + requirements.txt + test_demo.py`.

**Stack:** FastAPI + arq/Redis + Qdrant (hybrid dense+BM25) + Supabase Postgres/Storage + DeepSeek `deepseek-v4-flash` + Modal GPU (bge-m3, CLIP) + Streamlit.

**Repo:** `backend/app` (api/worker), `deploy/docker-compose.yml`, `frontend/`, `backend/app/core/schema.sql`. Env prefix `PRODRAG_` (`backend/app/config.py:6` reads `../.env` in Docker, `backend/.env` locally).

## 1. Architecture (v1)

```
                         ┌──────────────────────────────────────────────────┐
                         │                 FastAPI (api)                     │
                         │  /rd/analyze  /rd/research  /code/*  /query      │
                         │  /research  /documents  /files  /tools/search    │
                         │  /health                                          │
                         └───────┬──────────────────────┬───────────────────┘
                                 │                      │
               ┌─────────────────┘                      └─────────────────┐
               │ R&D Pipeline (idea → artifact)          │ Code Pipeline (artifact → demo)
               │ Analyzer (no KB, 2-req handshake)        │ Analyzer (artifact → CodingSpec)
               │ Orchestrator (fixed 5 dirs)               │ Orchestrator (fixed 3 files)
               │ Subagents x5 (rag_search + web fallback)  │ Subagents x3 (one LLM / file)
               │ Validator (emit-with-risks)                │ Tester (from spec, not code)
               │ Artifact (demo_spec + criteria)           │ Sandbox (tmpdir+subprocess)
               └──────────┬────────────────────────────────┴──────────┬───────┘
                          │  RAG Tool (tools/rag.py)                  │
                          │  search_kb() hybrid dense+BM25+rerank+CLIP│
                          │  Search Tool (tools/search.py) Tavily/Serper/generic
                          ▼                                           ▼
                 Supabase Postgres                              Qdrant / Redis / Storage
                 (documents, parts, research_runs,               (text_chunks, image_chunks,
                  research_artifacts, code_runs,                  episodes)
                  code_artifacts, conv)                          Supabase Storage (PDFs, figures)
                                                                 Redis (queue, conv:{session})
                                                                 Modal GPU (bge-m3, CLIP) + DeepSeek
```

**Layers:**

1. **RAG Tool** (`backend/app/tools/rag.py`) — wraps `backend/app/rag/retrieval.py:search_kb` (hybrid dense 1024 + BM25 `bm25`, RRF `Fusion.RRF`, optional cross-encoder `BAAI/bge-reranker-base` via `deploy/modal/rerank_service.py`, plus CLIP 512). Used by `/query`, legacy `/research`, R&D subagents.
2. **Search Tool** (`backend/app/tools/search.py`) — `web_search(query, k)` via Tavily → Serper → generic proxy; `enabled()` false → `[]` (RAG-only, never raises). R&D subagents auto-append when RAG `<2`; legacy agent exposes `web_search` as second tool when configured.
3. **R&D Pipeline** (`backend/app/rd/`) — analyzer → orchestrator → subagents → validator → artifact.
4. **Code Pipeline** (`backend/app/code/`) — analyzer → orchestrator → subagents → tester → sandbox → CodeArtifact. Python-only `demo.py` + `requirements.txt` + `test_demo.py`, toy data.
5. **Memory** — conversation `conv:{id}` (Redis, 20 msgs, 24h TTL) + episodic `episodes` (Qdrant `episodes` 1024, `vectorstore.py:_point_id` SHA-256).

## 2. Data Flow (v1)

### 2.1 Ingestion (async, `POST /documents`)

```
POST /documents (multipart file + metadata) → SHA-256 dedup (documents.content_hash)
  → Supabase Storage.put_bytes(docs/{id}/original.pdf)
  → db.document_upsert({id, title, source_key, content_hash, status:queued})
  → redis.enqueue_job("ingest_document", id, key, metadata)
  → worker arq (backend/app/worker.py:WorkerSettings, max_jobs=2, job_timeout=900)
    → pipeline.py:ingest_document — cleanup old parts (delete_points + delete_object + part_delete) → ensure_bucket/collections
      → get_bytes → parse_pdf (PyMuPDF: text + page render + figures/tables, page_dpi 150, min_figure_area 0.04)
      → chunk_text (RecursiveCharacterTextSplitter size 800 overlap 100) → text_payloads + texts
        → text_emb.embed_texts (Modal bge-m3 or OpenAI fallback) → upsert_text (dense+bm25 sparse)
      → figures: put_bytes(figures/{page}_{idx}.png) + ocr_extract (tesseract, graceful) → vision_emb.embed_images (CLIP) → upsert_image
        → ocr_text also upsert_text so text queries find figures
      → point_id("text"/"image", payload) deterministic SHA-256 → part_insert_many → document_update{status:done, text_chunks, images}
```

Re-ingest (`POST /documents/{id}/reingest`) cleans orphans first. Deterministic IDs make re-ingest idempotent.

### 2.2 Idea → Research → Code

```
User idea (free text)
  ──POST /rd/analyze {idea}────────────────────────► Analyzer (backend/app/rd/analyzer.py)
        │  {ready:false, questions:[1..3]}  ◄────────┘ (no KB, max 2 rounds)
        │  {ready:true, requirements:{goal, core_idea, demo_type:script|notebook, constraints, audience}}
        │  (second POST {idea, answers} forces ready:true, infer defaults)
        ▼
  POST /rd/research {requirements, session_id?, idea?}  (NDJSON)
        │  orchestrator/plan (5 dirs: core_algorithm, datasets, baselines, implementation_details, evaluation — fixed taxonomy, question = template.format(goal))
        │  subagent/start ─┐
        │  subagent/result ─┤  x5 (each: rag_search(direction.question, k=4) + web_search fallback when hits<2 → LLM synth → ResearchSummary{findings, sources, confidence: hit-count>=3 high/>=1 med else low, gaps})
        │  validator/result ─┤  LLM-as-judge {coverage:dir->bool, missing, feasible, risks} — emit-with-risks, never blocks, fallback = confidence heuristic
        │  artifact ─────────┘  ResearchArtifact{requirements, summaries[5], validation, demo_spec{entrypoint:demo.py, tech_stack, core_algorithm[:1200], pseudocode[:800], acceptance_criteria:["demo.py exits 0", "shape check", ... up to 5]}, sources deduped by source|page|content[:80], created_at}
        │  Persist: research_runs + research_artifacts (Supabase Postgres, best-effort, never fails stream)
        ▼
  POST /code/analyze {artifact: ResearchArtifact}
        │  → CodingSpec{file_tasks:[{path:demo.py, goal, context_slice},{path:requirements.txt},{path:test_demo.py}], test_intents, dependencies, risks}
        │     One json_object LLM call, no KB, fallback to demo.py|requirements.txt|test_demo.py + acceptance_criteria if LLM down
        ▼
  POST /code/generate {artifact, session_id?}  (NDJSON)
        │  code/plan {coding_spec, file_tasks}
        │  code/file_start|file_result x3  (one LLM call per FileTask, strips ``` fences, fallback per file)
        │  tester/result {test_demo.py}  (one LLM call FROM CodingSpec.test_intents + demo_spec.acceptance_criteria, not from demo.py — avoids tautology)
        │  sandbox/start
        │  sandbox/result {passed, pytest_log, demo_log, returncode, runtime_ms}  (tempfile.TemporaryDirectory + asyncio.to_thread(subprocess.run): pip install -r requirements.txt 60s, pytest test_demo.py -v, python demo.py 30s, never raises, timeout→passed=false)
        │  code/artifact {CodeArtifact{artifact_run_id, coding_spec, files:[GeneratedFile], test_file, sandbox, created_at}}  — files are [{path, content}]
        │  Persist: code_runs + code_artifacts (best-effort)
        ▼
  CodeArtifact — runnable: pip install -r requirements.txt && pytest && python demo.py
```

If idea precise, first `POST /rd/analyze` returns `ready:true`. Infeasible `validation.feasible:false` still emits (risks propagated to `CodeArtifact` and `acceptance_criteria`).

### 2.3 Query / Legacy Research

* `POST /query {question, k, k_images}` → `search_kb` (hybrid) → `answer()` (DeepSeek `deepseek-v4-flash`, text-only, figures as `object_key` refs unless `chat_supports_images`) → NDJSON `sources` then `text` deltas.
* `POST /research {question, session_id}` → `agent.py:research()` single tool-calling loop (orchestrator/researcher roles are prompt bundles, not processes; `ponytail:`), `kb_search` + optional `web_search` when `enabled()`, streams `memory/session`, `agent/tool_call`, `sources`, `agent/tool_result`, `text`, `memory/saved` (episodic memory auto-saved, conversation appended).

**Example — idea → demo (curl):**

```bash
TOKEN=change-me; API=http://localhost:8000

# 1. Analyze
curl -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"idea":"Turn Attention Is All You Need into a minimal demo"}' $API/rd/analyze | jq
# if ready:false, re-POST
curl -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"idea":"Turn Attention Is All You Need into a minimal demo","answers":["toy data","python script"]}' $API/rd/analyze | jq

# 2. Research (stream, save last line as artifact.json)
curl -N -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"requirements":{"goal":"demo attention","core_idea":"attention","demo_type":"script","constraints":[],"audience":"researcher","open_questions":[]},"idea":"demo attention"}' \
  $API/rd/research | tee /tmp/rd.ndjson
tail -1 /tmp/rd.ndjson | jq .data > /tmp/artifact.json

# 3. Code analyze
curl -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"artifact":'"$(cat /tmp/artifact.json)"'}' $API/code/analyze | jq

# 4. Code generate (stream)
curl -N -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"artifact":'"$(cat /tmp/artifact.json)"'}' $API/code/generate | tee /tmp/code.ndjson
tail -1 /tmp/code.ndjson | jq .data.files  # [{path:demo.py, content}, ...]

# 5. Search probe
curl -s -H "Authorization: Bearer $TOKEN" "http://localhost:8000/tools/search?query=transformer+2024&k=3" | jq
curl -s -H "Authorization: Bearer $TOKEN" -X POST -H "Content-Type: application/json" \
  -d '{"query":"transformer 2024","k":3}' http://localhost:8000/tools/search | jq

# 6. Local run of generated demo
jq -r '.[] | select(.path=="demo.py") | .content' /tmp/code.ndjson | tail -1 | jq -r '.data.files[] | select(.path=="demo.py") | .content' > /tmp/demo.py
python /tmp/demo.py
```

## 6. Search Tools

* `backend/app/tools/search.py:19` `enabled() = bool(tavily_api_key or serper_api_key or search_service_url)` — false → RAG-only, never raises.
* **Priority:** Tavily (`POST https://api.tavily.com/search {api_key, query, max_results, search_depth:basic}`) → Serper (`POST https://google.serper.dev/search {q, num}` + `X-API-KEY`) → generic proxy (`POST {search_service_url} {query,k}` + `Authorization: Bearer search_service_token`), each via `retry_async` (`backend/app/core/retry.py:1`, 3×, `>=500`/`429`/`TransportError`).
* **Generic proxy contract:** request `POST {query: str, k: int}`; response `{results:[{title,url,snippet}]}` or bare `[...]` (tolerates `title|name`, `url|link`, `snippet|content|text`). ProdRag example `deploy/search_proxy.py` (FastAPI) forwards to Tavily.
* **Integration:** `backend/app/agent.py:64` legacy agent adds `WEB_SEARCH_TOOL` when `enabled()` (second tool, formats via `format_results`, surfaces `kind:web` sources); `backend/app/rd/subagent.py:36` appends `web_search(direction.question, k=3)` when `len(text_hits)<2` and appends `kind:web` `source_items` (score 0).

**.env:**

```bash
# direct (no proxy)
PRODRAG_TAVILY_API_KEY=tvly-...
# or
PRODRAG_SERPER_API_KEY=...
# or generic proxy
PRODRAG_SEARCH_SERVICE_URL=http://localhost:8001/search
PRODRAG_SEARCH_SERVICE_TOKEN=change-me
PRODRAG_SEARCH_MAX_RESULTS=5

## 7. Code Pipeline Detail

* **Analyzer** (`backend/app/code/analyzer.py:1`): `analyze_artifact(client, artifact)` → `CodingSpec`. System prompt fixes `file_tasks` to `demo.py|requirements.txt|test_demo.py`, `test_intents` from `acceptance_criteria`, `risks` from `validation.risks`. One `json_object` call, sanitizes paths, ensures fixed set, never raises (fallback `_fallback`).
* **Orchestrator** (`backend/app/code/orchestrator.py:1`): `_coerce_coding_spec` + `build_code_plan(spec|artifact)` pure, deterministic, handles both `CodingSpec` dict/model and raw `ResearchArtifact` (fallback), sort order `demo.py, requirements.txt, test_demo.py`.
* **Subagent** (`backend/app/code/subagent.py:1`): `run_file_task(client, FileTask)` → `GeneratedFile`. Prompt `path+goal+context_slice`, strips ``` fences, fallback per path.
* **Tester** (`backend/app/code/tester.py:1`): `generate_tests(client, spec, artifact)` (accepts either arg order) → `GeneratedFile{path:test_demo.py}`. One LLM call from `CodingSpec.test_intents + demo_spec.acceptance_criteria` (prompt contains both verbatim — checked by `test_code_tester_spec.py:82` `demo.py exits 0`), fallback `def test_demo(): subprocess.run([sys.executable, 'demo.py'])`.
* **Sandbox** (`backend/app/code/sandbox.py:1`): `run_sandbox(files, timeout=15)` → `SandboxResult`. `tempfile.TemporaryDirectory` + `asyncio.to_thread(subprocess.run)` (pip 60s, pytest `test_demo.py -v`, `python demo.py` 30s), writes files via `_write_files`, never raises, timeout → `passed=false`, `ponytail: subprocess without cgroup, switch to docker+gvisor if untrusted`.
* **Pipeline** (`backend/app/code/pipeline.py:1`): `code_generate(client, artifact, session_id?)` — `analyze_artifact` → `build_code_plan` → `run_file_task` x3 sequential → `generate_tests` → `run_sandbox` → `CodeArtifact`. Streams events above, best-effort `code_run_create`/`code_artifact_upsert`/`code_run_update` (swallows DB errors like R&D).
* **Schemas** (`backend/app/code/schemas.py:1`): `FileTask{path, goal, context_slice}`, `CodingSpec{file_tasks, test_intents, dependencies, risks}`, `GeneratedFile{path, content}`, `SandboxResult{passed, pytest_log, demo_log, returncode, runtime_ms}`, `CodeArtifact{artifact_run_id, coding_spec, files, test_file, sandbox, created_at}`, `CodeAnalyzeRequest/Response`, `CodeGenerateRequest`.

## 11. Conventions & Pitfalls

* **No torch in api/worker images** — GPU on Modal. `uv sync --extra dev --extra modal --extra frontend` (all three).
* **Deterministic point IDs** — SHA-256(`kind+payload`) → UUID, idempotent re-ingestion.
* **Hybrid retrieval** — `qdrant_client` `1.19.x` `query_points()` (not `search()`), `FusionQuery(Fusion.RRF)` over `[Prefetch(dense), Prefetch(bm25)]`, fallback to dense if old collection lacks `bm25` sparse vector (boot warning, delete & re-ingest to enable).
* **429/500 retry** — `backend/app/core/retry.py:22` exponential backoff, `is_transient` checks `HTTPStatusError >=500|429` or `TransportError`.
* **404 handling** — `storage.delete_object` swallows 404; `document_by_hash` checks `status:done`.
* **Auth** — single `PRODRAG_API_TOKEN` exact `Bearer` match (`backend/app/api/__init__.py:8`), `GET /health` unauthenticated.
